# Data Notes

Raw data not included. Required columns:

| Column | Type | Description |
|---|---|---|
| `article_id` | str | Unique article ID |
| `text` | str | Full article or headline text |
| `topic_label` | str | Ground-truth topic category |
| `credibility_label` | int | 1 = credible, 0 = misleading |
| `source` | str | News outlet or platform |
| `date` | date | Publication date |
